Identification ($1A)

0x94 is a fixed software-identification string; 0x80 holds the BMW part number (ZB, packed BCD); 0x8F / 0x90 / 0x99 are the other EEPROM ident records. ZB and software ID are read on connect.

Fault memory ($18 / $14)

Reads DTCs by status and decodes each to its internal fault code(s), what they mean, and whether the fault switches ABS off and lights the ABS warning lamp (pin 44). Faults that only disable brake TCS / ASR or mark the yaw/steering sensors untrusted do not light the ABS lamp.

Vehicle coding ($23 / $3D)

EEPROM 0x0FA–0x0FC. The adjustment session and the 0x7F unlock are done for you (coding key field); effective next power-on.

Checksum = (row XOR field1) + 1, computed for you.

Valve calibration ($31 0x29 / 0x28, $33)

Actuates the valves and pump. Bench only. Run the outlet-valve learn (0x29) first, then the inlet (0x28); each is sent as 31 xx 00.

Brake bleeding ($30 10 07)

Runs the bleeding sequence: 104 valve / pump frames per side, about a minute. Runs the pump and pulses the valves. Bleeder screws of that side open, reservoir topped up, pedal pressure as per the procedure. On the M3 the same sequence is sent over CAN; unverified on that module.

ms

Single wheel, one-shot (30 10 07 00 00 FF <valves> 10): inlet + outlet valves of that wheel with the pump. Unverified.

Sensor offset calibration ($31 0x20–0x24)

Stationary required (NRC 0x22 if not ready). On the Z4 GT3, steering zero (0x21) also needs the SZL and the CAN key handshake.

CAN adapter test (PCAN-USB, WebUSB)

Opens a classic PEAK PCAN-USB directly from Chrome or Edge and lists the traffic on PT-CAN. Nothing is transmitted. Close PCAN-View and any Python tool using the adapter first.

Listen-only doesn't even ACK, so if the module is the only other node on the bus it repeats its first frames and may report errors. Untick it to ACK; frames are still never sent.
