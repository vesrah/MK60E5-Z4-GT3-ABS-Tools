Identification ($1A)

0x94 is a fixed software-identification string; 0x80 holds the BMW part number (ZB, packed BCD); 0x8F / 0x90 / 0x99 are the other EEPROM ident records. ZB and software ID are read on connect.

Fault memory ($18 / $14)

Reads stored DTCs by status and decodes each to its internal fault code(s), what they mean, and whether the fault switches ABS off and lights the ABS warning lamp (pin 44). Faults that only disable brake TCS / ASR or mark the yaw/steering sensors untrusted do not light the ABS lamp.

Vehicle coding ($23 read / $3D write)

2 bytes + checksum at EEPROM 0x0FA–0x0FC. The adjustment session and the 0x7F unlock are done for you (seedkey.json); takes effect at the next power-on.

Row selects the feature set (0–48). Checksum is computed for you.

Hydraulic valve calibration ($31 0x29 / 0x28, $33 status)

These routines actuate the valves and pump. Run only on a bench with the unit safe to pulse. Refused if a test is already active or the selector is not accepted. Run the outlet-valve learn (0x29) first, then the inlet (0x28); each is sent as 31 xx 00.

Brake bleeding ($30 10 07)

Runs the bleeding sequence: 104 valve / pump frames per side, about a minute. Runs the pump and pulses the valves. Bleeder screws of that side open, reservoir topped up, pedal pressure as per the procedure.

ms

Single wheel, one-shot (30 10 07 00 00 FF <valves> 10): inlet + outlet valves of that wheel with the pump. Unverified.

Sensor offset calibration ($31 0x20–0x24)

Car must be stationary; a not-ready routine replies NRC 0x22. Steering zero (0x21) also needs the SZL reporting initialised and the CAN key handshake.

Live data ($21)

0x02 conditioned sensors · 0x05 status byte · 0x06 raw ADC/sensors · 0x07 raw wheel speeds.

Memory read ($23)

Type 3 = EEPROM by address. Useful: 0x0FA coding, 0x160 steering/accel offset record, 0x0F0 steering key.
